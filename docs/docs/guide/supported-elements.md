# Supported Elements

| Element | Status | Notes |
|---------|--------|-------|
| Headings 1-6 | ✅ | `h1`..`h6` styles |
| Paragraph | ✅ | |
| Emphasis (bold, italic, strikethrough) | ✅ | `strong`, `em`, `codespan`, `del` |
| Link | ✅ | `link`, `linkImage` |
| Image | ✅ | + SVG |
| Blockquote | ✅ | |
| Inline Code | ✅ | `codespan` |
| Code Block | ✅ | `code` + `codeText` |
| List (ordered, unordered) | ✅ | |
| Horizontal Rule | ✅ | `hr` |
| Table | ✅ | `table` |
| React Components | ✅ | `useMarkdownWithComponents` |
| HTML | ❌ | Treated as plain text (see [#290](https://github.com/gmsgowtham/react-native-marked/issues/290)) |

Ref: [CommonMark](https://commonmark.org/help/)
